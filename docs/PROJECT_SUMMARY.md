# Layerforge: project summary

**What it is:** a local tool for music producers that builds new drum one-shots by combining the parts
you like (for example the body of one kick and the top of another) of 2–4 of your own samples of the
same type. It runs fully offline: a Python engine plus a browser page served from your own computer.
A JUCE VST3 plugin is the planned phase 2.

**Status:** milestone M1 (skeleton). The app starts and shows a "Layerforge works" page; the self-test
and the automatic tests run on Windows, macOS and Linux. The blending engine arrives in M2.

This file is completed in milestone M5.
